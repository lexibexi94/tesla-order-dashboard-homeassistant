# Tesla Order Tracker ausprobieren

Du brauchst Home Assistant ab 2026.11 und ein Administratorkonto.

1. [Tesla Order Tracker im Marketplace öffnen](https://my.home-assistant.io/redirect/marketplace_repository/?owner=lexibexi94&repository=tesla-order-dashboard-homeassistant&category=integration). Beim Hinzufügen kann Home Assistant dich bitten, einmal GitHub zu verbinden.
2. **Installieren** auswählen. Falls die Einrichtung danach nicht automatisch erscheint, gehe zu **Einstellungen → Geräte & Dienste → Integration hinzufügen → Tesla Order Tracker**.
3. **Demo ausprobieren** wählen und links **Tesla Order Tracker** öffnen.
4. Über **Änderung simulieren** siehst du, wie ein neues Lieferfenster und ein Übergabetermin im Verlauf erscheinen.
5. Für einen Test-Push in den Optionen der Integration ein Handy auswählen, das die Home Assistant Companion App bereits registriert hat. Demo-Nachrichten tragen einen entsprechenden Hinweis.

Du kannst den Tracker auch über **Einstellungen → Marketplace → Über Link hinzufügen** und die [Repository-Adresse](https://github.com/lexibexi94/tesla-order-dashboard-homeassistant) hinzufügen.

Für echte Bestellungen wähle **Mit Tesla anmelden (Rücksprungadresse einfügen)**. Die Anleitung im Dialog zeigt dir, wie du dich am Computer bei Tesla anmeldest und die einmalige Rücksprungadresse direkt in Home Assistant einfügst. Dieser Weg ist noch im Test.
